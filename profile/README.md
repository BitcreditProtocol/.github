## Repositories

**Protocol**

- [`cats`](https://github.com/BitcreditProtocol/cats) — protocol specifications
- [`Bitcredit-Core`](https://github.com/BitcreditProtocol/Bitcredit-Core) — core implementation, Rust
- [`bcr-common`](https://github.com/BitcreditProtocol/bcr-common) — types shared across repositories
- [`Governance`](https://github.com/BitcreditProtocol/Governance) — decentralised decision making

**Wallet**

- [`Wallet-Core`](https://github.com/BitcreditProtocol/Wallet-Core) — wallet core, Rust and WASM

**Credit mint**

- [`Wildcat`](https://github.com/BitcreditProtocol/Wildcat) — credit mint service
- [`Wildcat-Auxiliary`](https://github.com/BitcreditProtocol/Wildcat-Auxiliary) — auxiliary services
- [`wildcat-dashboard-ui`](https://github.com/BitcreditProtocol/wildcat-dashboard-ui) — admin dashboard

**Transport and infrastructure**

- [`bcr-relay`](https://github.com/BitcreditProtocol/bcr-relay) — Nostr relay
- [`nostr-postgres-db`](https://github.com/BitcreditProtocol/nostr-postgres-db) — Postgres storage backend for Nostr
- [`docker-external`](https://github.com/BitcreditProtocol/docker-external) — external images and compose configurations

**Shared**

- [`ui`](https://github.com/BitcreditProtocol/ui) — design system
- [`docs-bitcr`](https://github.com/BitcreditProtocol/docs-bitcr) — documentation site
- [`static-assets`](https://github.com/BitcreditProtocol/static-assets) — hosted static assets
- [`bcr-load-tests`](https://github.com/BitcreditProtocol/bcr-load-tests) — load testing harness

Some work happens in repositories that are not public, so this is not everything — and a public repository that is a fork of somebody else's project is left out rather than listed as ours. What is above is what we build and maintain in the open.

## Contributing

Read [CONTRIBUTING.md](https://github.com/BitcreditProtocol/.github/blob/master/CONTRIBUTING.md) first, and the [Code of Conduct](https://github.com/BitcreditProtocol/.github/blob/master/CODE_OF_CONDUCT.md).

## Security

Do not report vulnerabilities in a public issue. Use [security@bitcr.org](mailto:security@bitcr.org) or GitHub's [private advisory form](https://github.com/BitcreditProtocol/.github/security/advisories/new), as described in the [security policy](https://github.com/BitcreditProtocol/.github/blob/master/SECURITY.md).
